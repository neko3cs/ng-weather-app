# お天気アプリ（ng-weather-app）

Angularで構築された、シンプルで直感的なお天気アプリです。現在地の取得や都市名による検索で、詳細な気象情報を確認できます。

## 🚀 サービスリンク

[**お天気アプリ - GitHub Pages**](https://neko3cs.github.io/ng-weather-app/)

## ✨ 特徴

- **現在地取得**: Geolocation APIを使用して、今いる場所の天気をワンタップで表示。
- **都市検索**: Nominatim APIを利用した都市名検索機能。
- **詳細データ**: Open-Meteo APIから取得した、気温・湿度・風速・日の出/日の入り時刻などの詳細情報を表示。
- **レスポンシブデザイン**: Angular Materialを採用した、モダンで使いやすいUI。

## 🛠 使用技術

- **Framework**: Angular v21 (Standalone Components / Signals)
- **UI Library**: Angular Material
- **Testing**: Vitest
- **Data Source**:
  - [Open-Meteo API](https://open-meteo.com/) (気象データ）
  - [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) (逆ジオコーディング / 都市検索）
